# Roadmap

Forge focuses on a stable frontend SDK and a production x86-64 compiler core, while expanding the AArch64 backend and debugging/tooling support.

Potential future work includes:

- Native by-value aggregate ABI classification
- Variadic function definitions and calls
- Unwind and debug metadata
- Segmented live ranges and stronger register allocation
- Additional object and linker integrations
- Non-x86-64 targets
- Larger optimization and benchmark corpora

Roadmap items are not compatibility promises. Features become supported only after implementation, documentation, semantic coverage, platform coverage, and release-gate integration.
