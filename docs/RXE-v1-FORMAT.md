# RXE ISA v1 / Binary Format Reference

> Generated by `tools/generate-rxe-spec.py` from the Raz RXE implementation. Do not edit opcode numbers by hand.

- RXE container format: **v7**
- RXE instruction ISA: **v1**
- Header size: **104 bytes**
- Architectural registers: **32**
- Canonical instruction size: **8 bytes** (`opcode:u8 dst:u8 src0:u8 src1:u8 imm:u32`, little-endian)

## Section order

```text
header
function directory
code
constant pool
global image
aggregate layouts
callable signatures
exports
basic-block directory
```

## Compatibility invariant

Every emitted RXE file is read back by the Raz-side independent binary decoder. Section geometry and canonical reserved fields are validated, the image is re-encoded, and the result must be byte-identical before emission succeeds.
